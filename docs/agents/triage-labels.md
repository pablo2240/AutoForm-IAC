# Triage Labels

The five canonical labels used by `/triage` and related skills:

- `needs-triage`: Newly filed issues waiting for an initial review.
- `needs-info`: Issues blocked waiting for more details from the reporter.
- `ready-for-agent`: Issues well-specified and ready to be implemented autonomously by an AI agent.
- `ready-for-human`: Issues requiring human judgement, credentials, or non-automatable action.
- `wontfix`: Issues closed as out of scope or rejected.
